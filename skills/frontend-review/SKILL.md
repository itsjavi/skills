# Frontend Architecture Review Skill

Use this skill to review frontend codebases, features, pages, components, or proposed architecture.

## Review areas

Use the checklist in `references/review-checklist.md`.

## Output format

Prefer this structure:

```md
## Overall assessment

## What is good

## Main concerns

## Recommended changes

## Optional improvements

## Risk level
```

## Rules

- Prioritize concrete, actionable feedback.
- Separate blocking concerns from nice-to-haves.
- Consider project constraints and existing conventions.
- Prefer TypeScript-first, web-platform-first solutions when appropriate.
- Avoid recommending large libraries for small utilities unless justified.
