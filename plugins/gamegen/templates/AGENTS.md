# Game project conventions

Use `.agents/gamegen-prefs.json` for shared game choices. Read it through the GameGen preferences helper before production. Use the ask-question tools in bootstrap for unresolved choices, show recommended answers when appropriate, and never treat a preselection as a submitted answer.

Keep source art, exported assets, review evidence and task progress in their configured paths. Coordinate exclusive file ownership before parallel work and serialize shared-file or live-editor mutations. Follow the project's existing tracker workflow.

Inspect actual engine output before claiming visual completion. Measure performance separately from fixed-fps captures. Preserve ordinary saves during testing.

In generated text, connect clauses directly. Never use en dashes or em dashes to connect clauses or sentences.
