# Webcraft

Build and improve web applications with React, design guides, accessibility, metadata, rendering performance,
screenshots and commit messages.

Install this plugin in Codex, Claude Desktop or Claude Code using the
[repository setup instructions](../../README.md#plugins-setup). Its identifier is `webcraft`. Both platform manifests
load the same bundled skills.

## Included skills

- [design-guide-authoring](skills/design-guide-authoring/SKILL.md)
- [fix-page-metadata](skills/fix-page-metadata/SKILL.md)
- [fix-web-accessibility](skills/fix-web-accessibility/SKILL.md)
- [fix-web-rendering-performance](skills/fix-web-rendering-performance/SKILL.md)
- [generate-commit-message](skills/generate-commit-message/SKILL.md)
- [react-development](skills/react-development/SKILL.md)
- [ui-screenshots](skills/ui-screenshots/SKILL.md)

## Maintenance

Keep each skill and its supporting files together. Versions and marketplace metadata follow the
[shared repository release workflow](../../README.md#maintaining-plugins-and-releases).

The icon uses the same visual style as GameGen. Its prompt and provenance are recorded in
[icon-generation.json](assets/icon-generation.json).
